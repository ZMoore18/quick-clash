⚡ Quick Clash

A fast real-time target race for 2–6 players.

How to play
  1. Create a room or enter a 4-character room code.
  2. When the match starts, a target appears.
  3. Everyone races to click/tap it.
  4. The first valid hit earns 1 point.
  5. Targets disappear after 2.2 seconds if nobody hits.
  6. The match lasts 60 seconds. Highest score wins.
